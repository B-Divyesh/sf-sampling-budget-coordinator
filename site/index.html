02 / method

Budget math you can audit

The CLI needs a collector configuration, not trace data. It models supported sampler policies before estimating volume.

A / READ

Follow the traces pipeline

The CLI audits referenced processors and rejects unsupported sampling policies rather than making a quiet guess.

B / MODEL

Account for replicas by sampler type

Local adaptive-throughput goals scale with replicas. Percentage policies stay fractions of the load-balanced input.

C / ASSERT

Stop an over-budget deploy

Each scenario is checked against budget plus tolerance. Exit code 3 marks an over-budget assertion; JSON feeds CI.

03 / install

Put the check in CI

Build the Rust binary, run the bundled demo, then add the assertion to your deployment.

Shell / build and audit
cargo install --git https://github.com/B-Divyesh/sf-sampling-budget-coordinator

sbc demo

sbc plan --config collector.yaml \
  --budget 600 --replicas 3 \
  --scenario 3,5,8 --input 12000

sbc assert --config collector.yaml \
  --budget 600 --replicas 8 \
  --input 12000 --json

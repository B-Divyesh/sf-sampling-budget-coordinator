Policy / effective 28 August 2026

Privacy

Sampling Budget Coordinator is local by design. The website has no analytics, advertising, cookies, accounts, or server-side form submission.

Planner data

Values entered in the web planner stay in your browser memory and are discarded when the page closes. They are not stored or transmitted. The CLI reads the collector YAML path you provide and emits results locally. It does not read trace payloads or make network requests.

Configuration handling

The CLI parses the collector configuration you select in local process memory to inspect the traces pipeline. A collector configuration can contain endpoints, headers, identifiers, or credentials outside that pipeline. Sampling Budget Coordinator does not transmit, persist, or log any configuration contents.

Hosting logs

The static hosting provider may process ordinary request logs such as IP address, timestamp, and requested path for security and delivery. This project does not receive or combine those logs.

Contact and changes

Questions and proposed corrections can be filed in the public source repository. Material changes to this notice will be recorded in the project changelog.
